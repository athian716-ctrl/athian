# SDG 8 Demo Website

Simple static demo that highlights a problem related to Sustainable Development Goal 8 (Decent Work & Economic Growth) and shows a minimal HTML/CSS solution.

Preview
- Open `index.html` in your browser, or run a local static server from the project folder:

```bash
# Python 3
python3 -m http.server 8000
# then open http://localhost:8000
```

Next steps
- Add a small JavaScript layer to implement filtering and mock job-matching interactions.
- Add real content: local training resources, employer listings, and analytics.

Client-side demo
- A small client-side demo is included at `js/app.js` that seeds example candidates and provides simple filters by skill and location.

Deploy
- GitHub Pages: push the repo to GitHub and enable Pages from the `main` branch (or deploy from the `docs/` folder). No build step required for this static site.
- Netlify / Vercel: drag & drop the project folder or connect the repo — they auto-detect a static site.
